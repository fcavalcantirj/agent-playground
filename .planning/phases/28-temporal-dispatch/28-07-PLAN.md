**test_emit_inapp_outbound_activity.py — design-rationale lock-in:**

The Plan 04 body of `emit_inapp_outbound` is intentionally a success-path no-op. The actual outbox dual-write happens inside `mark_message_done` (atomic with the inapp_messages update). The workflow still calls `emit_inapp_outbound` separately because:

- It's a placeholder for a future "additional outbound side-effect" that doesn't need atomicity with mark_done.
- It preserves the conceptual symmetry of "after a reply lands, broadcast it to outbox channels" even if the current channel set is empty.
- It absorbs best-effort signaling for downstream observers without coupling to the mark_done transaction.

A future "tidy-up" PR could mistakenly delete the no-op emit_inapp_outbound activity call, OR — worse — mistakenly RE-ADD an `insert_agent_event` call inside emit_inapp_outbound (creating a second, non-atomic event row that the outbox pump would publish twice). This test prevents both regressions.

Skeleton:

```
import pytest
from temporalio.testing import ActivityEnvironment


async def test_emit_inapp_outbound_is_noop_for_success(pg_pool, seed_inapp_message_forwarded):
    msg_id, container_row_id = seed_inapp_message_forwarded
    # Pre-count agent_events for this container.
    async with pg_pool.acquire() as conn:
        pre = await conn.fetchval(
            "SELECT COUNT(*) FROM agent_events WHERE agent_container_id=$1",
            container_row_id,
        )

    from api_server.temporal.activities.emit_inapp_outbound import emit_inapp_outbound
    # If the activity is a free function (preferred per Plan 03 stub layout):
    sample_event_input = {
        "message_id": str(msg_id),
        "container_row_id": str(container_row_id),
        "user_id": "00000000-0000-0000-0000-000000000002",
        "agent_id": "00000000-0000-0000-0000-000000000003",
        "kind": "inapp_outbound",
        "payload": {"text": "hi back"},
    }

    env = ActivityEnvironment()
    result = await env.run(emit_inapp_outbound, sample_event_input)
    assert result is None  # success-path no-op

    async with pg_pool.acquire() as conn:
        post = await conn.fetchval(
            "SELECT COUNT(*) FROM agent_events WHERE agent_container_id=$1",
            container_row_id,
        )
    assert post == pre, (
        "emit_inapp_outbound MUST be a success-path no-op — the dual-write lives in "
        "mark_message_done (covered by test_mark_done_atomic_success). If this test "
        "fails because emit_inapp_outbound now inserts an agent_events row, the "
        "outbox pump will publish the event TWICE (once per row). Revert the change "
        "or rework mark_message_done to remove its insert_agent_event call."
    )
```

If the Plan 04 implementation made emit_inapp_outbound a class method (`EmitActivities(db_pool=...).emit_inapp_outbound`), adapt the import + invocation accordingly.
