## Spacing Scale

Solvr Labs uses an 8-point scale. All widget padding / margin / gap MUST
draw from this table. Multi-pixel offsets (e.g. 12, 20) are NOT permitted
without an entry in the Exceptions section below.

| Token | Value | Flutter usage | Where it appears |
|-------|-------|---------------|------------------|
| xs | **4 px** | `EdgeInsets.all(4)` / `SizedBox(height: 4)` | Inline icon-to-text gap inside buttons; status-dot to label gap (D-08, D-14); 1px divider hairlines stay at thickness 1 (Phase 24 dividerTheme already locks this). |
| sm | **8 px** | `EdgeInsets.all(8)` | Chat bubble inner padding tight axis; tab bar item spacing; small caption gaps (D-15, D-20). |
| md | **16 px** | `EdgeInsets.symmetric(horizontal: 16)` | Default screen horizontal padding; list row vertical padding; bubble inner padding loose axis; `TextField` content padding (D-08, D-35, D-40). |
| lg | **24 px** | `EdgeInsets.all(24)` | Section padding inside the wizard; gap between OAuth buttons; gap between stepper bar and step body (D-04, D-23). |
| xl | **32 px** | `EdgeInsets.all(32)` | Vertical breathing room above the empty-state ASCII banner; padding around the `>_ SOLVR_LABS` wordmark on Login + retry screen (D-02, D-04, D-17). |
| 2xl | **48 px** | `SizedBox(height: 48)` | Major page-level breaks (e.g. between wizard step indicator and the next "Next" button). |
| 3xl | **64 px** | `SizedBox(height: 64)` | Top-of-viewport offset for the Login wordmark; bottom safe-area + FAB clearance on Dashboard. |

### Exceptions (declared per CONTEXT decisions)

| Value | Where | Why |
|-------|-------|-----|
| **44 pt iOS / 48 dp Android** | All tappable elements (FAB, icon buttons, list rows, send button, retry tap targets, OAuth buttons, model-picker rows, recipe cards, status menu items) | WCAG 2.1 + Apple HIG + Material guidelines floor. Phase 24 D-21 captured the floor; D-62 enforces. |
| **2 px** | Border thickness for the SELECTED recipe card (D-25), failed-bubble border (D-44), focused `TextField` outline (Phase 24 theme `focusedBorder` already 1px — Phase 25 keeps default; selected-card uses 2px explicitly to communicate selection vs hover/idle states). | D-25, D-44 |
| **1 px** | Divider between Dashboard rows; default `OutlineInputBorder` thickness; stepper rule between step circles (D-23). Already encoded in `solvrTheme.dividerTheme.thickness=1`. | Phase 24 theme |
| **~50 px scroll threshold** | "User scrolled up" detection on Chat (D-42). Used to gate auto-scroll-to-bottom; appears once in Chat scroll-controller logic, NOT in widget padding. | D-42 |

## Typography

Phase 24 ships `bodyTextTheme` via `GoogleFonts.interTextTheme(base)` and
`mono(...)` via `GoogleFonts.jetBrainsMono(...)`. Phase 25 declares the
**4 size tokens** + **2 weight tokens** every screen MUST draw from.
Anything else is forbidden — no inline `fontSize: 13`, no `FontWeight.w300`.

### Size tokens (4 — locked)

| Role | Size | Flutter | Where it appears |
|------|------|---------|------------------|
| **caption** | **12 px** | `Theme.of(context).textTheme.bodySmall!` | Bubble timestamps (D-47), step labels under stepper bar (D-23), input hint captions (D-54), `last_activity` relative time (D-15), wizard step indicator labels, model id under agent name on Dashboard rows (D-08, D-16). |
| **body** | **16 px** | `Theme.of(context).textTheme.bodyLarge!` | Default screen body. Agent name on Dashboard (D-08), chat bubble body (D-35), `TextField` input text, button labels, picker row primary text, dialog body. |
| **heading** | **20 px** | `Theme.of(context).textTheme.titleMedium!` | Step title in wizard ("Pick a clone" / "Pick a model + key" / "Name + deploy"), AlertDialog title, AppBar title (`>_ SOLVR_LABS` wordmark on Dashboard rendered at this size in JetBrains Mono). |
| **display** | **28 px** | `Theme.of(context).textTheme.headlineSmall!` | Login wordmark `>_ SOLVR_LABS` (centered), retry-screen wordmark (D-02), Dashboard empty-state heading "No agents yet" (D-17). |

### Weight tokens (2 — locked)

| Token | Weight | Flutter | Used for |
|-------|--------|---------|----------|
| **regular** | **400** | `FontWeight.w400` | Body, captions, hints, list labels, bubble content, secondary text (default for `Inter`). |
| **semibold** | **600** | `FontWeight.w600` | Wordmark `>_ SOLVR_LABS` (JetBrains Mono); section headings; primary CTA button labels; selected-step indicator; "Sign out" menu item; Dashboard agent name (subtle emphasis vs the model-id mono caption). |

> Resolves D-Discretion: the wordmark is **JetBrains Mono w600**.
> No w500 / w700 / italic anywhere except the Chat empty-state "Say hi to
> {agent_name}" hint (D-38) which uses `Inter w400 italic` — italic is a
> typographic VARIANT of the body token, not a third weight.

### Line height

| Role | Line height | Why |
|------|-------------|-----|
| Body / caption / chat-bubble content | **1.5** (`height: 1.5`) | Body legibility default. Markdown rendering inherits. |
| Heading / display / wordmark | **1.2** (`height: 1.2`) | Tight headings — wordmark especially needs tight tracking. |

### Mono usage rule

`JetBrains Mono` is reserved for: the wordmark, model ids
(`anthropic/claude-haiku-4-5`), recipe names on cards (D-25), code fences
inside markdown (D-43), the ASCII agent-name banner on Dashboard empty
state (D-17), and the wizard's BYOK input field text (D-34 — `font-mono`
mirroring the web playground). Everywhere else uses Inter.

## Color

Solvr Labs is a **monochrome 2-color palette** (background + foreground)
with **two semantic accents** (running + destructive/failed). The 60/30/10
split below maps the conventional split onto a flat monochrome palette.

| Role | Hex | Flutter token | Usage |
|------|-----|---------------|-------|
| **Dominant (60%)** | `#FAFAF7` | `SolvrColors.background` (Phase 24) → `colorScheme.surface` | Scaffold background, AppBar background, dialog background, empty-state surface, wizard step background, message-list background, light/empty surfaces. |
| **Secondary (30%)** | `#1F1F1F` | `SolvrColors.foreground` (Phase 24) → `colorScheme.primary` + `colorScheme.onSurface` | All body text, list-row label text, AppBar foreground, primary button background (foreground inverts to background on the button), divider text contexts. The user-bubble background on Chat (D-35 — black bubble with white text). |
| **Tertiary surface** | `#FFFFFF` (`SolvrColors.card`) and `#EFEFEC` (`SolvrColors.muted`) | already on theme | Card surface (lighter than scaffold for elevation cue when needed); muted area for assistant chat bubble background (D-35), code-fence grey background (D-43), greyed disabled-tab fill (D-10), greyed-input background (D-49). |
| **Border / muted-foreground** | `#DEDEDA` (`SolvrColors.border`) and `#6B6B6B` (`SolvrColors.mutedForeground`) | already on theme | List row divider, `OutlineInputBorder` idle, "scrolled up" `New message ↓` chip border, muted secondary text (timestamp captions, model id under agent name), step-indicator hollow circles. |

### Accents (10% — strictly reserved)

| Accent | Hex | Flutter token | **Reserved for ONLY these elements** |
|--------|-----|---------------|--------------------------------------|
| **Running green** | `#22C55E` | `SolvrColors.success` (NEW — Phase 25 adds to `solvr_theme.dart`) | (1) `StatusDot` in `running` state on Dashboard rows (D-14). (2) `StatusDot` in `running` state inside Chat AppBar status subtitle (D-37). **Nowhere else.** Not on buttons, not on banners, not on text, not on icons. |

### Accent reserved-for list (explicit, no exceptions)

```

  - StatusDot.running  (Dashboard rows, Chat AppBar subtitle)

#D9333A (destructive red):
  - StatusDot.failed
  - FailedBubble border + warning glyph
  - Login OAuth error caption
  - Wizard name-validation error caption + TextField border
  - Wizard smoke-fail inline error box
```

### Accent FORBIDDEN locations (executor-checked)

- ❌ FAB background (uses foreground `#1F1F1F`, NOT green)
- ❌ Primary CTA button (uses foreground `#1F1F1F` — D-04, D-17)
- ❌ Send button when active (uses foreground `#1F1F1F`)
- ❌ Selected recipe card border (uses foreground `#1F1F1F` 2px — D-25)
- ❌ Stepper "current" filled circle (uses foreground `#1F1F1F` — D-23)
- ❌ Restart banner background (uses muted grey, NOT red — D-49)
- ❌ Telegram-failed banner background (D-50 — uses muted grey/yellow tint, NOT pure destructive red; the warning glyph carries the semantic, the banner stays calm)

> Rationale: Solvr Labs is a flat monochrome brand. Color is a SIGNAL,
> not decoration. Green = running. Red = something failed. Anything else
> is black-on-white.

## Copywriting Contract

All copy is **en-US, sentence-case** (NOT Title Case). Concise. Verb-first
on CTAs. No marketing language ("Awesome!", "Boom!", "Let's go!"). No
emoji EXCEPT the warning glyph `⚠` on failure surfaces (D-44, D-49, D-50)
and `↓` on the new-message scroll chip (D-42). Solvr Labs Matrix aesthetic
prefers plain ASCII over emoji.

### Copy NOT permitted in this phase

- ❌ "Are you sure?" (use the action verb in the title — `Sign out of Solvr Labs?`, not `Are you sure you want to sign out?`)
- ❌ "Oops!" / "Whoops!" / "Something went wrong" (vague — name the actual failure)
- ❌ "Please" anywhere (UI copy, not chat text)

- ❌ Telegram-specific labels hardcoded in Dart ("Bot Token", "User ID") — labels MUST come from `recipe.channels.telegram.required_user_input[i].env` per D-54.

## Component Inventory (Flutter widgets — D-61)

### 1. `StatusDot` — `lib/shared/status_dot.dart`

**Purpose:** D-14 — three-state status indicator on Dashboard rows + Chat
AppBar subtitle.

```dart
class StatusDot extends StatelessWidget {
  const StatusDot({
    required this.status,  // 'running' | 'stopped' | 'exited' | 'failed' | 'error'
    this.size = 8,
    super.key,
  });
  final String status;
  final double size;
}
```

**Visual contract:**
- `running` → filled circle, fill `#22C55E`, no border, size 8 px (default).
- `stopped` / `exited` → hollow ring, border 1 px `#6B6B6B`, transparent fill.
- `failed` / `error` → filled circle, fill `#D9333A`.
- Unknown state → hollow ring, border 1 px `#DEDEDA`, transparent fill.
- Wrap with `Semantics(label: 'Agent status: $status')` for screen readers.

### 2. `EmptyStateScaffold` — `lib/shared/empty_state_scaffold.dart`

**Purpose:** D-17 + Chat empty state — centered area with optional

class EmptyStateScaffold extends StatelessWidget {

### 3. `AsciiAgentBanner` — `lib/shared/ascii_agent_banner.dart`

**Purpose:** D-17 — Matrix-aesthetic cycling JetBrains Mono banner.

```dart
class AsciiAgentBanner extends ConsumerWidget {
  const AsciiAgentBanner({
    required this.namesStream,  // Stream<List<String>> (Riverpod-supplied; default sourced from GET /v1/recipes)
    this.intervalMs = 2000,
    super.key,
  });
}
```

**Visual contract:**
- Renders ONE name at a time, JetBrains Mono w600, size 28 px, centered.
- Cycles every 2000 ms. Cross-fades via `AnimatedSwitcher(duration: 300ms, switchInCurve: Curves.easeInOut, switchOutCurve: Curves.easeInOut)` (resolves D-Discretion).
- Names are sourced from the live `recipes` provider — **NEVER hardcoded** (Golden Rule #2).
- Falls back to a static `["solvr_labs"]` if the recipes stream is empty/loading (graceful degradation).
- No background — sits on the scaffold surface.

### 4. `RetryBanner` — `lib/shared/retry_banner.dart`

**Purpose:** D-19 (Dashboard inline retry) + D-50 base (Telegram-failed
banner extends this with a custom title prop).

```dart
class RetryBanner extends StatelessWidget {
  const RetryBanner({
    required this.message,        // e.g. "Couldn't refresh"
    required this.actionLabel,    // e.g. "Tap to retry" / "Retry"
    required this.onTap,
    this.dismissible = false,
    this.onDismiss,
    this.tone = RetryBannerTone.muted,  // muted | warning
    super.key,
  });
}
enum RetryBannerTone { muted, warning }
```

**Visual contract:**
- `muted`: bg `#EFEFEC`, fg `#1F1F1F`, no border on top.
- `warning`: bg `#EFEFEC` (same — no red), fg `#1F1F1F`, prefix with `⚠` icon (16 px) inline.
- Caption 12 px message + body 16 px action label, action label is a `TextButton` foreground-color text.
- If `dismissible`: trailing `×` icon (24 dp tap target — Material `IconButton`) → `onDismiss`.
- 48 dp min height for accessibility.
- Full-width, no horizontal margin (sits flush in scaffold).

### 7. `FailedBubble` — `lib/shared/failed_bubble.dart`

**Purpose:** D-44 — distinct bubble for `status='failed'` messages.
